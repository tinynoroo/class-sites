# class-sites

[English](README.md) | **한국어**

학생이 만든 웹사이트를 폴더째 올리면 바로 공개되는 갤러리입니다.

웹사이트 만들기 수업용으로 만들었습니다. 학생마다 주소를 하나 정하고 폴더를 올리면 공유할 수 있는 URL이 바로 생기고, 모두의 사이트가 갤러리 한 페이지에 모입니다.

## 사용 흐름

1. **업로드.** `index.html`이 들어 있는 폴더를 고르고, 주소(`/sites/<주소>/`)를 정하고, 이름과 비밀번호를 입력합니다.
2. **공개.** 폴더가 그 주소에서 정적 사이트로 서비스되고, 갤러리에 카드가 추가됩니다.
3. **수정.** 갤러리 카드에서 비밀번호를 입력하면 제목을 바꾸거나 파일을 교체할 수 있습니다.

## 세부 사항

- **폴더 통째 업로드.** 선택한 최상위 폴더 이름은 떼어 내므로 `my-site/index.html`은 `index.html`로 서비스됩니다. `Index.html`, `INDEX.HTML` 같은 이름도 맞춰 줍니다.
- **원자적 교체.** 파일을 임시 폴더에 쓴 뒤 한 번에 바꿔 끼우므로, 반쯤 올라간 사이트가 보이는 일이 없습니다.
- **불필요한 파일 제외.** 점(.)으로 시작하는 파일, `node_modules`, `__MACOSX`, `Thumbs.db`, `desktop.ini`는 업로드할 때 걸러집니다.
- **사이트별 비밀번호.** salt를 넣은 scrypt 해시로 저장합니다. 10번 틀리면 그 사이트는 10분간 잠깁니다.
- **제한.** 사이트당 파일 1,000개, 100MB까지(`MAX_UPLOAD_MB`).
- **사용자 404 페이지.** 사이트에 `404.html`이 있으면 그것을 씁니다.
- **데이터베이스 없음.** 사이트와 메타데이터는 `storage/` 아래 일반 파일입니다.

## 실행

```
npm install
npm run dev
```

Docker로 실행할 수도 있습니다.

```
docker compose up --build
```

compose 파일은 `127.0.0.1:9006`에 바인딩하고 `dbnet`이라는 외부 Docker 네트워크에 참여합니다. [noroo-deploy](https://github.com/tinynoroo/noroo-deploy)로 관리하는 서버용으로 작성했기 때문입니다. 단독으로 실행하려면 네트워크를 먼저 만들거나(`docker network create dbnet`) `networks` 줄을 지우세요.

| 변수 | 기본값 | 의미 |
|---|---|---|
| `STORAGE_DIR` | `storage` | 업로드한 사이트와 메타데이터를 저장할 위치 |
| `MAX_UPLOAD_MB` | `100` | 사이트당 전체 용량 제한 |

## 스택

Next.js(App Router), React, TypeScript. 데이터베이스와 외부 서비스를 쓰지 않습니다.

## 신뢰 범위에 대해

업로드된 사이트는 갤러리와 같은 출처(origin)에서 서비스되고, 업로드 페이지에 접근할 수 있는 사람은 누구나 사이트를 올릴 수 있습니다. 누가 올리는지 아는 교실 환경에는 맞지만, 인터넷에 열어 둔 공개 호스팅 서비스로 쓰기 위한 것은 아닙니다.
